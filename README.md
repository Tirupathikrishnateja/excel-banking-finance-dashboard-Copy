# Banking & Finance Dashboard | Microsoft Excel

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel to organize, analyze, and visualize banking and financial data through a dashboard.

The objective is to transform structured spreadsheet data into meaningful summaries and visual reports that help users explore financial performance, compare categories, and monitor key indicators.

The project showcases practical spreadsheet analysis, formula-based calculations, data summarization, and dashboard design for business reporting.

## 🎯 Project Objectives

- Organize and analyze structured banking and financial data.
- Summarize key financial indicators in an accessible dashboard.
- Compare values across available categories and reporting periods.
- Identify patterns and trends within the available dataset.
- Present analytical results through charts and KPI summaries.
- Demonstrate Excel skills relevant to entry-level Data Analyst roles.

## 🔄 Data Analysis Workflow

### 1. Data Inspection

Review the source dataset to understand its structure, column names, data types, and available financial attributes.

### 2. Data Cleaning

Check for missing values, duplicate records, inconsistent categories, and incorrect data formats where applicable.

### 3. Data Preparation

Prepare the data for analysis by standardizing fields and ensuring numerical values and dates are stored in appropriate formats.

### 4. Analysis and Aggregation

Use relevant Excel functions, summaries, and PivotTables to calculate metrics and compare values across the available categories.

### 5. Dashboard Development

Present the results through charts, KPI cards, summary tables, and other visuals supported by the workbook.

### 6. Validation

Cross-check dashboard values against the underlying dataset and confirm that filters and formulas work correctly.
