# Banking & Finance RFM, Cohort, KPI and KRA Dashboard

## Overview
A Microsoft Excel dashboard focused on banking and finance metrics, including RFM/cohort-style analysis and KPI/KRA reporting. Explore the workbook sheets, formulas, pivot tables, and charts to understand the metrics and underlying assumptions.

## Tools
- Microsoft Excel
- Dashboard visuals, worksheet calculations, and KPI reporting (as present in the workbook)

## Files
- `Banking_Finance_RFM_Cohort_KPI_KRA_Dashboard.xlsx` — the project workbook.

## How to review
1. Download the workbook from this repository.
2. Open it in Microsoft Excel (desktop recommended).
3. Review the worksheets, formulas, pivot tables, charts, and any filters/slicers included.
4. Add screenshots to this README after confirming the workbook displays correctly.

## Data and validation
Before publishing, inspect the workbook for confidential financial data, hidden sheets, and personal information.

Do not add unverified performance claims. Document the exact KPIs and findings after checking the workbook.
